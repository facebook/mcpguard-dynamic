# Security Policy

## Reporting a Vulnerability

Meta takes the security of our software products and services seriously, including all of the open-source code repositories managed through our GitHub organizations.

If you believe you have found a security vulnerability in MCPGuard-Dynamic — including a policy-bypass in the proxy, an eBPF-program flaw, or a benchmark case that demonstrates a previously-undisclosed MCP attack — please report it through Meta's security bounty program:

<https://www.facebook.com/whitehat>

Please do **not** open a public GitHub issue for security reports.
